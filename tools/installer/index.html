ButtHeat firmware installer

Connect the ButtHeat board (or any ESP32-C3 dev board flashed for it) over USB, then click Connect. This installs the latest release: bootloader, partition table and application in one image. Existing device data is erased.

Requires a browser with Web-Serial support: desktop Chrome, Edge or Firefox (not iOS — on iPhones use the device's Wi-Fi OTA update mode instead).

Firmware files for manual esptool flashing are on the releases page. After installing, you can update in the car without a cable: hold the left knob's button while switching ignition on and follow the display.
